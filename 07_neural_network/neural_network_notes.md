# 07 · 神经网络（XOR）知识卡片

> **本章定位**：第一次用**框架**搭真正的神经网络，并用它攻克一个**线性不可分**的经典问题。解决的核心问题是——**隐藏层为什么能拟合单层做不到的边界**。
>
> **承上启下**：内建在 06 的 dense 之上；向后被 08（多分类/多标签）、09（CNN）继承，训练流程完全一致。

## 知识地图

```
神经网络（解决 XOR）
├─ 问题        XOR 线性不可分，单个逻辑回归无法拟合
├─ 关键       隐藏层做特征变换，把原空间「撑开」成线性可分
├─ 结构       2 → 3(sigmoid) → 1(sigmoid)
├─ 激活       linear / sigmoid / ReLU   + 为什么必须有非线性
├─ 训练流程   数据准备→搭建→编译→训练→评估预测→可视化
├─ 编译三件套 损失 binary_crossentropy / 优化器 Adam / 指标 accuracy
├─ 训练超参   epochs / batch_size
└─ 可视化     学习曲线(loss+acc) + 决策边界(网格预测+contourf)
```

## 核心知识点卡片

### 1. 为什么需要神经网络：XOR 问题

- **数据**：在 [0,1]² 内均匀采样 1000 个点；两特征是否「同侧」（都 >0.5 或都 ≤0.5）决定标签。
- **为什么单层做不到**：异或的判定边界是「两条交叉直线」围成的十字区域，**线性不可分**，一个逻辑回归画不出；必须靠隐藏层先做非线性变换。

### 2. 隐藏层的意义

```
输入空间（异或不可分）
   → 隐藏层：非线性变换，把样本映射到新空间
   → 新空间里变得线性可分
   → 输出层：做一次线性划分
```

- **本质**：隐藏层**自动学习新的特征表示**，替代了 05 里手工构造的多项式特征。

### 3. 激活函数

| 激活 | 表达式 | 用在哪 | 注意 |
|---|---|---|---|
| linear | z | 回归输出层 / logits 输出层 | 不引入非线性 |
| sigmoid | 1/(1+e^-z) | 二分类输出层、小网络隐藏层 | 两端梯度趋 0，深网络里易梯度消失 |
| ReLU | max(0, z) | 隐藏层默认选择 | 计算快；可能出现「死亡」神经元 |

- **为什么必须非线性**：若全是线性层，多层叠加仍等价于**一层线性变换**，加深毫无意义。

### 4. 网络结构：2 → 3 → 1

```
输入     2 个特征
隐藏层   3 个神经元 + sigmoid（XOR 至少需要 2 个才能“撑开”空间）
输出层   1 个神经元 + sigmoid —— 二分类只需 1 个输出，值即“为正类的概率”
```

### 5. 训练流程（六步）

```
1) 数据准备   采样 + 按规则打标签（二分类用 0/1）
2) 搭建模型   Sequential 顺序堆叠 Dense，第一层声明输入维度
3) 编译       损失 / 优化器 / 指标
4) 训练       fit 循环：前向 → 算损失 → 反向 → 更新
5) 评估预测   evaluate 算损失指标；predict 得概率
6) 可视化     学习曲线 + 决策边界
```

### 6. 编译三件套

```
损失   binary_crossentropy（配 sigmoid 二分类输出）
优化器 Adam（自适应学习率，比原始梯度下降收敛快）
指标   accuracy（只影响打印/监控，不参与训练）
```

> **损失与激活必须配套**：sigmoid 输出配二分类交叉熵；错配会导致梯度错误或 loss 变 NaN。

### 7. 训练超参

```
epochs      迭代轮数：太少欠拟合，太多易过拟合
batch_size  每批样本数：权重每处理完一个 batch 更新一次
history     保存每轮 loss / accuracy，供画学习曲线
```

### 8. 决策边界可视化

```
1) 平面上铺网格
2) 每点喂给模型得概率，reshape 回网格
3) contourf 用颜色深浅表示「标签为 1 的概率」
4) 叠加真实散点，看分界是否合理
```

### 9. 关于 GPU（本章的一段重要备注）

```
小任务（如本例 1000 样本、13 个参数）GPU 不会更快，甚至更慢
    原因：GPU 核函数启动 + 数据拷贝的开销 > 计算本身
GPU 真正有优势的场景：样本量上万、batch 调大、或换成卷积网络
原生 Windows 上 TensorFlow ≥ 2.11 不支持 GPU，高版本要用 WSL2
```

## 易错点 / 常见坑

| 坑 | 说明 |
|---|---|
| 隐藏层神经元太少 | XOR 至少需要 2 个隐藏神经元才能线性可分 |
| 激活/损失错配 | sigmoid 输出必须配二分类交叉熵 |
| 指标当损失 | `metrics` 只用于打印，真正决定梯度的是 `loss` |
| 小任务迷信 GPU | 数据/参数太少时 GPU 反而更慢 |
| 忘记固定随机种子 | 采样/初始化不可复现 |
| 边界图不做网格 | 决策边界靠「网格逐点预测 + 等高线」，不能直接画 |
