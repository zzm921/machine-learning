# 05 · 逻辑回归 知识卡片

> **本章定位**：从「拟合连续值」跨到「**判类别**」。解决的核心问题是——**输出要落在 (0,1) 当概率，代价要是凸的才好梯度下降**。本章含两个主题：**基础逻辑回归**与**正则化 + 多项式特征的逻辑回归**。
>
> **承上启下**：复用 04 的缩放 / 代价 / 梯度 / 可视化框架；sigmoid 与交叉熵是 07/08 神经网络输出层的基础。

---

## 知识地图

```
逻辑回归
├─ 为什么不用线性回归分类   输出无界 + 平方误差非凸
├─ sigmoid 函数            σ(z)=1/(1+e^-z)  → 压到 (0,1)，σ'=σ(1-σ)
├─ 假设函数                h = σ(X·θ)
├─ 决策边界                X·θ = 0  的曲面（模型属性，非数据属性）
├─ 交叉熵代价              J=(1/m)·Σ[-y·log h-(1-y)·log(1-h)]
├─ 梯度                    (1/m)·Xᵀ(h-y)   ← 与线性回归同形
├─ 数值稳定                clip 防止 log(0)=inf
└─ 进阶（第二个脚本）
   ├─ 特征映射 map_feature   n 个特征 → degree 次以内全部多项式项
   ├─ L2 正则化             代价加 (λ/2m)·Σθ²（θ₀ 不算）
   └─ λ 对比                0 过拟合 / 1 适中 / 100 欠拟合
```

---

## 核心知识点卡片

### 1. 为什么分类不能用线性回归

```
输出范围   线性回归可输出任意实数；分类要的是「概率」，必须落在 (0,1)
代价函数   线性回归的平方误差套在 sigmoid 上会变成非凸函数，梯度下降易陷局部最优
```

### 2. sigmoid 函数

```
σ(z) = 1 / (1 + e^(-z))      把任意实数压到 (0,1)
导数 σ'(z) = σ(z)·(1-σ(z))    这是梯度能写出漂亮形式的根源
```

- **作用**：把 `X·θ` 这个「分数」转成「属于正类的概率」。

### 3. 假设函数与决策边界

```
假设   h(x) = σ(X·θ)
判定   h ≥ 0.5 预测 1，否则 0   ← 等价于 X·θ ≥ 0
边界   令 X·θ = 0 得到的曲面，就是决策边界
```

- **关键认知**：决策边界是**模型的属性**（取决于 θ），不是数据的属性；特征映射后边界可以是曲线。

### 4. 交叉熵代价函数

```
J(θ) = (1/m)·Σ[ -y·log(h) - (1-y)·log(1-h) ]
```

- **为什么不用平方误差**：平方误差配 sigmoid 会得到非凸代价；交叉熵是凸的，且对「自信地错」惩罚极大（h 接近 0/1 而标签相反时，loss → ∞），学习信号更强。

### 5. 梯度：和线性回归「长得一样」

```
∂J/∂θ = (1/m)·Xᵀ·(h - y)
```

- 形式与 04 完全相同（只是 h 由 `X·θ` 换成了 `σ(X·θ)`）——这正是逻辑回归优雅之处。

### 6. 数值稳定（高频坑）

```
h 可能被 sigmoid 压到极接近 0 或 1 → log(0) = -inf → cost = NaN
解法：把 h 限制在 [1e-10, 1-1e-10] 之间再取 log
```

### 7. 决策边界的绘制（缩放空间 → 原始空间）

```
θ 是在缩放后的空间求得的，画边界要「反变换」回原始特征空间：
1) 原始空间取 x1 的绘图范围，按训练 μ/σ 缩放
2) 在缩放空间解 X·θ = 0，得到对应的 x2
3) 把 x2 反缩放回原始尺度，画出这条线
4) 限制坐标轴范围，避免边界线延伸过远把散点挤成一团
```

### 8. 特征映射 map_feature（第二个脚本的核心）

- **是什么**：把 n 个原始特征扩展成 degree 次以内的**所有多项式项**。
- **为什么**：数据线性不可分时，用高次项把样本映射到更高维，在那里可能线性可分。
- **数量公式**：`C(degree + n, n)`——2 个特征、degree=3 时为 `C(5,2)=10`（含偏置列）。
- **实现思路**

```
输出 = [全1列] + 总次数=1 的全部单项式 + 总次数=2 的 + ... + 总次数=degree 的
       （“有放回”地从特征里取 d 个相乘，覆盖所有指数组合）
```

### 9. L2 正则化

```
代价   J = 原交叉熵 + (λ/2m)·Σ_{j≥1} θ_j²
梯度   普通梯度 + (λ/m)·θ，但 θ₀ 置 0（偏置不参与惩罚）
```

- **为什么**：特征映射后参数变多、极易过拟合；惩罚大权重能压低模型复杂度。
- **λ 的作用**：λ 越大约束越强。

| λ | 表现 | 现象 |
|---|---|---|
| 0 | 过拟合 | 边界弯曲缠绕样本，训练准确率高但泛化差 |
| 1 | 适中 | 边界平滑，训练/泛化平衡 |
| 100 | 欠拟合 | 惩罚过强，边界接近直线、欠拟合 |

### 10. 缩放要作用于多项式特征

- 多项式项数值尺度差异巨大（x² 比 x 大得多），必须**先映射、再缩放**；偏置列保持全 1 不缩放。

## 易错点 / 常见坑

| 坑 | 说明 |
|---|---|
| `log(0)` 得 NaN | sigmoid 输出取 log 前要 `clip` 到极小区间 |
| 正则化惩罚了偏置 | `θ₀` 必须排除在正则项之外（梯度里置 0） |
| λ 过大 | 参数被压向 0，退化成欠拟合 |
| 边界画在缩放空间 | 必须先反变换回原始尺度再画 |
| 多项式特征不缩放 | 高次项量纲悬殊，不缩放梯度会失控 |
| 混淆「训练准确率」与「泛化」 | λ=0 时训练准确率高，不代表模型好，要结合边界形态判断 |
| 特征映射后忘加偏置 | `map_feature` 输出的第 0 列就是全 1 偏置，不要重复加 |
