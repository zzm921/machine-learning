## 2. 里程碑卡片（逐代拆解）

### 2.1 生物起点：感受野（Hubel & Wiesel，1959–1962）

- **要解决的问题**：视觉系统到底怎么「看」？
- **核心发现**：猫视觉皮层的神经元有**局部感受野**，只对视野中一小块区域响应；并存在「简单细胞（对边缘方向敏感）→ 复杂细胞（对位置不那么敏感）」的分层结构。
- **结构骨架**

```
输入像素（视野）
 → 低层细胞：只看局部小块，检测边缘 / 方向        # 局部感受野
 → 高层细胞：把低层响应组合，检测更复杂的模式      # 分层组合
```

- **影响**：为 CNN 提供了两条最核心的设计直觉——**局部连接**与**逐层抽象**。
- **局限**：只是生理学观察，没有给出可训练的计算模型。

---

### 2.2 结构雏形：Neocognitron（Fukushima，1980）

- **要解决的问题**：怎么把「分层局部」变成可运行的网络？
- **核心创新**：把细胞抽象成两类层，交替堆叠：
  - **S 层（simple）**：做局部加权求和，本质是卷积，并对位置不敏感
  - **C 层（complex）**：做局部聚合（类似池化），容忍微小位移
  - 多层结构逐级提取越来越抽象的**特征**；同一层的不同位置**共享**同一组权重（权值共享雏形）
- **结构骨架**

```
输入图像
repeat:
    S 层：对上一层做局部加权求和（卷积）      # 特征提取
    C 层：对邻域做下采样 / 取最大（池化）      # 位移容忍
→ 顶层输出类别
```

- **影响**：现代 CNN 的「卷积 + 池化 + 分层」结构在这里已经定型。
- **局限**：靠无监督的自组织学习，**没有反向传播**，难以在大任务上训练；规模小。

---

### 2.3 训练落地：卷积 + 反向传播（LeCun，1989）

- **要解决的问题**：Neocognitron 学不动、不通用。
- **核心创新**：把**卷积结构**与**反向传播**结合，让整个网络可以端到端按梯度训练；用于手写邮编识别，落地到真实系统。
- **结构骨架**

```
前向   逐层做 卷积 / 池化 / 全连接，得到预测
损失   与真实标签比较，算误差
反向   沿网络回传梯度（卷积层也有对应梯度公式）
更新   用梯度下降调整卷积核与全连接权重
```

- **影响**：CNN 从「结构设想」变成「可训练方法」，是工业界第一次大规模使用。
- **局限**：受限于当时的算力与数据规模，没能推广到复杂视觉任务。

---

### 2.4 范式定型：LeNet-5（1998）

- **要解决的问题**：把前述思想固化成一个可复用的经典骨架。
- **核心创新**：确立「**卷积 → 池化**」反复堆叠、最后接全连接输出的范式；用平均池化做下采样，激活用 tanh/sigmoid。
- **结构骨架**

```
输入 32×32×1
→ Conv(5×5, 6)   + 池化
→ Conv(5×5, 16)  + 池化
→ Conv(5×5, 120)
→ Flatten → FC(84) → FC(10)
新积木：卷积与池化交替、参数量极小（约 6 万）
```

- **影响**：此后几乎所有 CNN 都是它的变体，是 CNN 的「Hello World」。
- **局限**：网络浅、算力要求低但也**容量有限**；无法处理彩色、大尺度、多类别的复杂图像。

---

### 2.5 沉寂期（1998–2012）

CNN 没落不是因为理论错了，而是**三个条件都不成熟**：

```
数据   缺大规模带标注数据集（ImageNet 2009 才出现）
算力   缺 GPU 并行，深层训练慢到不可行
方法   深网络难训：梯度消失 / 初始化敏感 / 易过拟合
```

同时期 SVM、手工特征（SIFT/HOG）在小数据上表现更好，抢走了注意力。

---

### 2.6 复兴：AlexNet（2012）

- **要解决的问题**：深度网络「训不动、训不好」。
- **核心创新**：一组工程 + 方法组合拳，让深 CNN 首次碾压传统方法（ILSVRC 2012 top-5 错误率 15.3%，远超第二名 26.2%）：
  - **ReLU** 替代 sigmoid/tanh → 梯度不饱和、训练更快
  - **Dropout** → 抑制过拟合
  - **数据增强**（裁剪、翻转、颜色扰动）→ 变相扩数据
  - **双 GPU 并行**，把模型拆到两张卡上训练
  - **重叠最大池化**、局部响应归一化（LRN）
- **结构骨架**

```
输入 227×227×3
→ Conv(11×11, s=4, 96) + ReLU + MaxPool
→ Conv(5×5, 256)       + ReLU + MaxPool
→ Conv(3×3, 384) + Conv(3×3, 384) + Conv(3×3, 256) + ReLU + MaxPool
→ Flatten → FC(4096)+ReLU+Dropout → FC(4096)+ReLU+Dropout → FC(1000) → Softmax
新积木：ReLU、Dropout、数据增强、GPU、重叠池化、LRN
```

- **影响**：点燃深度学习浪潮，验证了「**大数据 + 大算力 + 深模型**」这条路。
- **局限**：参数量巨大（约 6000 万，绝大部分压在三个全连接层），大卷积核（11×11）计算冗余。

---

### 2.7 加深：VGG（2014）

- **要解决的问题**：AlexNet 结构不规则、全连接层臃肿，感受野大核太浪费。
- **核心创新**：**用多个 3×3 小卷积核堆叠替代一个大卷积核**，配合统一规整的模块化结构：
  - 两层 3×3 的有效感受野 = 一个 5×5；三层 3×3 = 一个 7×7
  - 小核堆叠**参数更少**、且**非线性更强**（每层后都接激活）
- **结构骨架**

```
输入 224×224×3
分块，每块 = [Conv(3×3)+ReLU] × n + MaxPool
块内通道数翻倍：64 → 128 → 256 → 512 → 512
→ Flatten → FC(4096) → FC(4096) → FC(1000)
代表作 VGG-16 / VGG-19（16 / 19 层带权层）
```

- **影响**：「小核 + 深」成为共识；VGG 的结构规整使其成为迁移学习的常用骨干。
- **局限**：**极重**（约 1.38 亿参数），依然是全连接层吃掉大部分参数与显存。

---

### 2.8 加宽 + 多尺度：GoogLeNet / Inception（2014）

- **要解决的问题**：只要更深就更好吗？如何**又深又省**？
- **核心创新**：
  - **Inception 模块**：同一层里**并行**跑 1×1、3×3、5×5 卷积和池化，再拼接 → 一次拿到**多尺度**特征
  - **1×1 卷积降维**：在昂贵大核前先压通道，大幅省算力（bottleneck 思想）
  - **全局平均池化**替代最后的大全连接层 → 参数骤降
- **结构骨架**

```
Inception 模块(输入 X):
    b1 = Conv1x1(X)
    b2 = Conv1x1(X) → Conv3x3
    b3 = Conv1x1(X) → Conv5x5
    b4 = MaxPool      → Conv1x1
    输出 = 拼接(b1, b2, b3, b4)          # 多尺度并存
主干：堆叠 Inception 模块 → 全局平均池化 → FC(1000)
新积木：1×1 卷积、多分支并行、全局平均池化、辅助分类头
```

- **影响**：证明「**网络结构可以精心设计得更高效**」；22 层却只有约 500 万参数，比 VGG 轻一个量级。
- **局限**：结构复杂（分支多、超参多），手工设计成本高。

---

### 2.9 突破深度：ResNet（2015）+ BatchNorm

- **要解决的问题**：网络加到几十层后，**训练误差反而上升**——这**不是过拟合，而是退化（degradation）**：太深的网络难以学到「恒等映射」，优化困难。
- **核心创新**：
  - **残差 / 跳连**：让模块学**残差** `F(x)` 而非直接学目标 `H(x)`，输出为 `F(x) + x`。若某层无用，网络可轻松把 `F(x)` 学成 0，退化为恒等映射 → **深网络至少不比浅网络差**
  - **Bottleneck 块**：1×1 降维 → 3×3 → 1×1 升维，省算力
  - **BatchNorm**：按小批量对激活做归一化，缓解梯度消失、可用更大学习率、降低初始化敏感
- **结构骨架**

```
残差块(输入 x):
    h = Conv(x) → BN → ReLU
    h = Conv(h) → BN
    输出 = ReLU(h + x)         # 恒等跳连：核心是那个 “+ x”
Bottleneck 块：Conv1x1 降维 → Conv3x3 → Conv1x1 升维 + 跳连
主干：堆叠残差块，可到 50 / 101 / 152 层，甚至上千层
```

- **影响**：一举拿下 ILSVRC 2015 冠军，"跳连"成为几乎所有后续深层网络的标配。
- **局限**：更深不总是更好（收益递减）；跳连带来额外的显存与访存开销。

---

### 2.10 连接的新范式：DenseNet（2016）

- **要解决的问题**：残差是**相加**（跳连），特征信息在极深处仍可能衰减。
- **核心创新**：**密集连接**——每一层都接收**前面所有层**的输出（**拼接**而非相加），实现最大化的特征复用；配合 1×1 瓶颈层与过渡层控制通道增长。
- **结构骨架**

```
Dense 块(输入特征列表 [x0]):
    x1 = Conv([x0])
    x2 = Conv([x0, x1])
    x3 = Conv([x0, x1, x2])     # 每层吃前面全部
    ...                          # 用拼接 concat 汇合
过渡层：Conv1x1 + 池化，压缩通道
```

- **影响**：同等精度下参数更少、梯度流动更好；启发了大量特征复用设计。
- **局限**：拼接导致显存占用高，实现与调参更复杂。

---

### 2.11 高效化：MobileNet（2017）

- **要解决的问题**：手机 / 边缘设备算力和内存有限，标准卷积太重。
- **核心创新**：**深度可分离卷积**——把标准卷积拆成两步：
  - **逐深度卷积**：每个输入通道**各自**用一个卷积核（不跨通道）
  - **逐点卷积**：用 1×1 卷积做通道融合
  - 计算量约为标准卷积的 1/8 ~ 1/9；再配**宽度乘子**、**分辨率乘子**进一步缩放
  - MobileNetV2 提出**倒残差 + 线性瓶颈**（在低维用线性、不在瓶颈处用 ReLU，减少信息损失）
- **结构骨架**

```
标准卷积  = 一次算完：空间 + 通道一起卷积          # 贵
深度可分离 = 逐深度卷积(每通道独立) → 逐点卷积(1×1 融合)   # 省 8~9 倍算力
新积木：宽度乘子 α、分辨率乘子 ρ、倒残差、线性瓶颈
```

- **影响**：轻量网络成为移动端标配，后续衍生出 MobileNetV3、EfficientNet-Lite 等。
- **局限**：绝对精度通常略低于同代重型网络。

---

### 2.12 注意力登场：SENet（2017）

- **要解决的问题**：卷积对各通道**一视同仁**，但不同通道的重要性其实不同。
- **核心创新**：**通道注意力（SE 模块）**，两步：
  - **Squeeze**：全局平均池化，把每个通道压成一个数（通道描述符）
  - **Excitation**：两层全连接（含 ReLU、sigmoid）学出每个通道的权重
  - 用权重对原特征**逐通道加权（重标定）**
- **结构骨架**

```
SE 模块(输入特征图 U, 通道数 C):
    s = 全局平均池化(U)              # Squeeze：C 维向量
    w = sigmoid(FC(ReLU(FC(s))))     # Excitation：学 C 个通道权重
    输出 = U × w                     # 逐通道缩放
可插入任意卷积块之后（即插即用）
```

- **影响**：ILSVRC 2017 冠军；开启「**注意力 + CNN**」方向，成为后续网络的常见组件。
- **局限**：引入额外参数与轻微延迟；只是通道维度注意力，未涉空间。

---

### 2.13 自动搜架构：NAS / EfficientNet（2019）

- **要解决的问题**：手工设计网络太靠经验，且「加宽 / 加深 / 提高分辨率」三者的**缩放比例**没有定论。
- **核心创新**：
  - **NAS（神经架构搜索）**：用搜索算法自动找网络结构
  - **EfficientNet**：先用 NAS 搜出一个紧凑基线，再用**复合缩放**——用一个系数按**固定比例**同时放大**深度、宽度、输入分辨率**，而非单独放大某一维
- **结构骨架**

```
基线网络（NAS 搜出，如 MBConv 堆叠）
复合缩放：depth   = α^φ
          width   = β^φ
          resolution = γ^φ      # α·β²·γ² ≈ 2，φ 为统一缩放系数
一次调 φ 就整体放大，比例由网格搜索确定
```

- **影响**：以极少参数达到当时 SOTA，说明**缩放策略本身**也是设计维度。
- **局限**：NAS 搜索成本高；复合缩放的固定比例对下游任务未必最优。

---

### 2.14 新范式之争与融合：ViT（2020）→ Swin / ConvNeXt（2022）

- **要解决的问题**：Transformer 在 NLP 大获成功后，图像能不能也「只用注意力」？
- **核心创新**：
  - **ViT**：把图像切成固定大小的**图块（patch）**，当作序列 token 喂给标准 Transformer；丢掉卷积的局部先验，**用海量数据**补偿
  - **Swin Transformer**：引入**层次化 + 移动窗口**，把注意力限制在窗口内并逐级下采样，重新找回卷积式的多尺度与效率
  - **ConvNeXt**：反向操作——把 ResNet **现代化**（大核深度卷积、LayerNorm、GELU、更少激活、倒瓶颈）去对齐 Transformer 的设计，证明「**纯卷积**在同等训练策略下也能打平 ViT」
- **结构骨架**

```
ViT：图像 → 切 patch → 线性嵌入 + 位置编码 → Transformer 编码器 × N → 分类头
         （无卷积先验，强依赖大数据 / 强增强）

ConvNeXt：ResNet 骨架 + 大核深度卷积(7×7) + LayerNorm + GELU + 倒瓶颈
         （用 Transformer 时代的设计元素改造卷积网络）
```

- **影响**：焦点从「卷积 vs 注意力」转为「**归纳偏置 + 数据规模 + 训练策略** 如何配合」；两条路线开始融合（混合 CNN-Transformer、ConvNeXt、Swin 并存）。
- **局限**：纯 ViT 小数据下易过拟合；注意力计算量随分辨率平方增长（窗口 / 层次化是为缓解此问题）。

---

## 3. 横向专题：把演进串成几条线

演进不是散点，而是几条技术线各自推进、互相交织：

### 3.1 感受野与权值共享（CNN 的两条根本假设）

```
局部连接   每个神经元只看局部区域   → 参数少、符合图像局部性
权值共享   同一卷积核在全图滑动复用 → 参数更少、带来平移不变性
分层堆叠   感受野逐层扩大           → 从边缘 → 纹理 → 部件 → 物体
```

### 3.2 卷积核尺寸的演变

```
大核 (11×11 / 7×7, AlexNet)       感受野大但参数多、计算冗余
  → 小核堆叠 (3×3, VGG)           同感受野更少参数、更多非线性
  → 1×1 卷积 (NiN / GoogLeNet)    通道降维、跨通道信息融合，不改变空间尺寸
  → 深度可分离卷积 (MobileNet)    空间与通道解耦，大幅省算力
  → 大核深度卷积 (ConvNeXt 7×7)   Transformer 时代的“回归大核”，但用深度卷积省算力
```

### 3.3 深度难题与对策

```
梯度消失 / 初始化敏感  → BatchNorm / 残差连接 / 更好的激活(ReLU)
退化问题（深反而差）   → 残差跳连（学残差而非映射）
信息衰减（极深）       → 密集连接（拼接式特征复用）
过拟合                → Dropout / 数据增强 / 归一化 / 早停
```

### 3.4 多尺度与注意力

```
多尺度：Inception 并行多核  → 特征金字塔 / 层次化下采样（Swin）
注意力：通道注意力(SENet)  → 空间注意力 / 自注意力(ViT)
共同点：都让网络“按需加权”，而非对所有位置 / 通道一视同仁
```

### 3.5 从手工设计到自动搜索

```
手工设计 (LeNet → ResNet)：靠直觉与实验，迭代慢、依赖专家
自动搜索 (NAS / EfficientNet)：把结构当搜索空间，用算法找
缩放策略 (复合缩放)：不改结构，只按比例整体放大
反思 (ConvNeXt)：极端自动化之外，好的手工设计 + 现代训练策略同样有效
```

## 4. 演进主线小结

```
阶段一「结构」  感受野 → 局部+共享+分层 → 卷积-池化范式      解决「怎么算」
阶段二「训练」  反向传播 → ReLU/BN/残差 → 深度可训练          解决「怎么训得深」
阶段三「效率」  小核堆叠 / 1×1 / 深度可分离 / 注意力 / 缩放    解决「又准又省」
阶段四「融合」  ViT 挑战卷积 → 卷积现代化与混合架构           解决「归纳偏置 vs 数据规模」
```

一条判断线索：**每一代的“新积木”几乎都在回答同一个问题——在给定算力预算下，如何让网络更深 / 更宽 / 更多尺度 / 更关注重要信息，同时不退化、不过拟合。**
