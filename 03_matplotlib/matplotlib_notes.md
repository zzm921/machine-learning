## 知识地图

```
一次绘图的标准流程
   准备数据 → 画(kind) → 装饰(xlabel/ylabel/title/legend) → show()
├─ 数据准备   linspace 生成均匀的 x
├─ 画图       plot(折线) / scatter(散点) / bar(柱) / imshow(图像) / contour(等高线)
├─ 装饰       xlabel / ylabel / title / legend / grid / xlim / ylim
├─ 多子图     subplots(1, 2)  一次画并排多张
├─ 样式参数   color / linestyle / linewidth / marker / markersize / label
└─ 中文显示   rcParams 配置字体与负号
```

## 核心知识点卡片

### 1. 标准绘图流程（本章主线）

```
1) 准备 x（常用 linspace 生成均匀点）
2) plt.plot(x, y, label=...) 画曲线，label 供图例用
3) plt.xlabel / plt.ylabel / plt.title 加轴标签与标题
4) plt.legend() 显示图例
5) plt.show() 弹窗显示（阻塞，逐个关掉才继续）
```

### 2. 准备数据：linspace

- **是什么**：在区间内生成**等间隔**的若干点，常用来当 x 轴。
- **为什么**：画曲线需要「平滑密集」的 x，而不是原始散点。
- **怎么用**

```
x = linspace(0, 2, 100)   # 0 到 2 之间取 100 个等间隔点（含两端）
```

### 3. plot 的关键参数

```
plot(x, y,
     color      线色，默认蓝
     linestyle  线型，'-' 实线 / '--' 虚线
     linewidth  线宽
     marker     数据点标记，如 'o'
     markersize 标记大小
     label      图例名（与 legend() 配套）)
```

### 4. 多条曲线叠加

- **做法**：连续多次 `plot`，每条给 `label`，最后一次 `legend()` 一起显示。
- **效果**：同一坐标里对比不同函数/不同模型，如 `x`、`x²`、`x³` 三条线。

### 5. 图例 legend 的意义

- 图例是「线的身份说明」，只有给了 `label` 的曲线才会出现在图例里。
- 多条线时**必须**加图例，否则看不出谁是谁。

### 6. 中文与负号显示（**本章埋的钩子**）

- **问题**：默认字体不含中文字形 → 中文变方块；负号也可能显示成方块。
- **做法**（04 起每章都会先配）

```
rcParams 字体             设为 ['Microsoft YaHei','SimHei','SimSun'] 等中文字体
rcParams 负号             关闭 unicode_minus 的替换
```

### 7. 常用图类型（本章之外的延伸，后续章节会用到）

| 图 | 用在哪 | 关键点 |
|---|---|---|
| `plot` 折线 | 代价/学习曲线 | 看趋势与收敛 |
| `scatter` 散点 | 原始数据分布 | 用 marker 区分正负样本 |
| `bar` 柱状 | 计数/对比 | 分组对比用并排柱 |
| `imshow` 图像 | 显示灰度/彩色图 | 灰度用 `cmap='gray'`，彩色不要 |
| `contour` / `contourf` 等高线 | 决策边界 | 画 0.5 概率的等值线即边界 |
| `subplots` 多子图 | 并排对比 | 一次布局多张图 |

### 8. 决策边界可视化的通用套路（后续章节反复出现）

```
1) 在平面上铺一张密集网格
2) 把网格每点喂给模型，得到预测概率
3) 把概率 reshape 回网格形状
4) 画「概率 = 0.5」的等高线 = 决策边界
```

## 易错点 / 常见坑

| 坑 | 说明 |
|---|---|
| 中文变方块 | 没配中文字体；先设 `rcParams` 字体，再关掉负号替换 |
| 多条线没有图例 | 只画线不给 `label`，`legend()` 就是空的 |
| 忘了 `show()` | 图画好了但没调用显示，窗口不弹 |
| 窗口阻塞 | `show()` 是阻塞的，多个图要逐个关掉；本仓库每章末尾常连弹好几张 |
| 灰度图乱用色图 | `imshow` 灰度要 `cmap='gray'`；彩色图不能加 |
| 坐标范围被拉飞 | 边界线延伸过远会把散点挤成一团，需 `xlim` / `ylim` 收范围（04/05 会踩） |
