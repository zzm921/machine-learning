## 核心知识点卡片

### 1. 为什么要向量化（本章的总纲）

- **是什么**：把「对每个元素逐个运算」写成「整个数组一起运算」，如 `arr + 10`。
- **为什么**：Python 的 for 循环是解释执行、逐元素开销大；ndarray 在**连续内存**中存储，运算下沉到**预编译的 C 代码**里批量完成，快几个数量级，且更接近数学符号。
- **怎么用**

```
慢（逐元素循环）  for i: out[i] = arr[i] + 10
快（向量化）      out = arr + 10
```

### 2. 创建数组

- **是什么**：从序列/形状生成 ndarray 的一组构造器。
- **为什么**：不同场景要不同的初始值——占位、全零、序列、等分。
- **怎么用**

```
array([1,2,3])       从序列建，可 dtype 指定类型
zeros((2,3))         全 0
ones((2,3))          全 1
empty((2,3))         只分配内存、不初始化（值是内存残留）
arange(4,10)         起点/终点/步长，类似 range，不含终点
linspace(0,1,5)      起点/终点/个数，含两端，等间隔
```

> `arange` 管「步长」，`linspace` 管「个数」——这是两者最本质的区别。

### 3. 四个常用属性

```
ndim    维度数（几个轴）
shape   形状元组，每个元素 = 该轴长度
size    元素总数 = shape 各维相乘
dtype   元素数据类型（决定内存与精度）
```

### 4. 取数：索引 / 切片 / 迭代

- **索引**：`arr[0]` 取单个；多维可 `arr[i, j]`。
- **切片**：`arr[1:3]`、`arr[:2]`、`arr[1:]`，规则同 Python 切片（左闭右开）。
- **迭代**：直接 `for v in arr` 拿值；`ndenumerate` 同时拿「下标 + 值」。

### 5. 两类运算：逐元素 vs 矩阵

```
数组 ⊙ 标量    arr + 10 / arr * 10 / arr ** 2     # 每个元素分别算（广播）
数组 ⊙ 数组    A * B                              # 位置对应相乘（逐元素）
矩阵乘法       A @ B  等价 A.dot(B)              # 线性代数意义上的乘法
```

> **最容易混的一点**：`*` 是逐元素乘，`@` / `dot` 才是矩阵乘法，两者结果完全不同。

### 6. 广播机制（Broadcasting）

- **是什么**：形状不同的数组做运算时，NumPy 自动把「小数组」按规则扩展成大数组的形状再加（等价于复制多份）。
- **为什么**：避免显式写循环或手动复制，代码更简洁、内存更省。
- **规则**：从**最右侧维度**对齐比较，某维要么相等、要么其中一个为 1（为 1 则沿该维复制展开）。
- **怎么用**

```
标量 + 数组        标量被复制成整个数组的形状
(3,1) 与 (1,4)     逐维广播 → 结果 (3,4)
```

### 7. 统计函数

```
sum / mean / max / min / std(标准差) / var(方差)
```

> 多维数组可指定 `axis` 沿某个轴统计；本仓库后面按列统计（`axis=0`）用得最多。

### 8. 变形：reshape / flatten / resize / transpose

```
reshape((3,1))     改形状，元素总数必须不变
flatten()          拉平成一维（返回拷贝）
resize((2,2))      改形状，元素不够就循环填充
transpose()        转置（行列互换）
```

### 9. 拼接与拆分

```
vstack  垂直方向堆叠（加行）
hstack  水平方向并排（加列）
vsplit  垂直切开成若干块
hsplit  水平切开成若干块
```

### 10. 拷贝 vs 视图（**高频坑**）

- **拷贝 `copy()`**：新数组、新内存，改它**不影响**原数组。
- **视图 `view()`（以及切片、reshape 等产生的结果）**：与原数组**共享内存**，改视图会**连带改到原数组**。

```
b = a.view()      # b 与 a 共享内存
b[0] = 999        # a[0] 也变成 999 ！
c = a.copy()      # c 独立，改 c 不影响 a
```

> 需要一份独立副本时，**显式 `copy()`**，不要指望赋值或切片自动拷贝。

### 11. 线性代数

```
A @ B / A.dot(B)   矩阵乘法
np.eye(3)          单位矩阵
A.trace()          矩阵的迹（对角线元素之和）
```

### 12. 直方图

```
hist, bins = np.histogram(arr, bins=5)   # hist: 每个区间的计数; bins: 区间边界
```

## 易错点 / 常见坑

| 坑 | 说明 |
|---|---|
| `*` 当成矩阵乘 | `*` 是逐元素乘，矩阵乘要用 `@` 或 `dot` |
| 视图改到原数组 | 切片/`view`/`reshape` 的结果常与原数组共享内存，要独立副本用 `copy()` |
| `empty` 以为是全 0 | `empty` 只分配内存、不初始化，值是残留垃圾 |
| `arange` / `linspace` 混用 | 前者给「步长」、不含终点；后者给「个数」、含两端 |
| 类型悄悄变化 | 整数数组做 `/` 会变浮点；需要控制精度就显式指定 `dtype` |
| 广播维度对不上 | 从右侧对齐，维度既不相等也不为 1 就会报错 |
