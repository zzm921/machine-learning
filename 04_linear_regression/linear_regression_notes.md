# 04 · 线性回归 知识卡片

> **本章定位**：第一个**完整的学习闭环**——数据 → 模型 → 代价 → 梯度下降 → 可视化验证 → 预测。解决的核心问题是——**怎么用一条直线（超平面）拟合连续值，并让它自己从数据里学出来**。
>
> **承上启下**：用到 01 的 ndarray 矩阵运算、02 的读表、03 的绘图；向后被 05（换成分类）、06（写成 dense 层）继承。

---

## 知识地图

```
线性回归
├─ 问题设定    单特征(人口→利润) / 多特征(面积+卧室→房价)
├─ 假设函数    F(X) = X·θ       偏置并入 θ，X 首列补全 1
├─ 特征缩放    标准化 (x-μ)/σ   让梯度下降更快更稳
├─ 代价函数    J(θ) = 1/(2m)·Σ(F(X)-y)²
├─ 优化        批量梯度下降  θ := θ - α·(1/m)·Xᵀ(Xθ-y)
├─ 超参        α 学习率 / epoch 迭代次数
└─ 验证        拟合效果图(A) + 收敛曲线(B) + 预测
```

---

## 核心知识点卡片

### 1. 问题设定

- **单特征**：`ex1data1.txt`，第 0 列人口 → 最后一列利润。
- **多特征**：`ex1data2.txt`，面积 / 卧室数 → 房价。
- **统一读法**：`read_csv(header=None)`；特征 = `iloc[:, :-1]`，目标 = `iloc[:, -1]`。
- **通用性**：代码不写死特征个数，单/多特征只靠切列区分，可平滑切换。

### 2. 假设函数：把偏置并入 θ

```
F(X) = X · θ
其中 X 的第一列固定为全 1，θ[0] 就是原来的偏置 b
```

- **为什么**：偏置 b 单独写会让公式和梯度都多一项；把它变成「对应输入恒为 1 的权重」后，模型退化成纯粹的矩阵乘法，代码更统一。

### 3. 特征缩放（标准化）

- **是什么**：每个特征分别减均值、除以标准差 → 均值 0、方差 1。
- **为什么**：多特征量纲差异大（面积上千、卧室个位数）时，代价函数等高线会非常细长，梯度下降来回震荡、收敛慢；缩放到同一量级后等高线接近圆形，下降更快更稳。
- **怎么用**

```
X = (X - mean(X, axis=0)) / std(X, axis=0)   # 按列（逐特征）缩放
X = 拼接([全1列], X)                          # 再补偏置列
```

> **关键约束**：预测新样本时，**必须用训练时同一套 μ / σ** 做缩放，否则尺度不一致、预测错误。

### 4. 代价函数

```
J(θ) = 1/(2m) · Σ (F(X_i) - y_i)²
```

- **是什么**：所有样本「预测值 - 真实值」的平方的平均（再乘 1/2）。
- **为什么用平方**：平方让正负误差都变正、且大误差惩罚更重；是凸函数，保证梯度下降能到全局最优。
- **为什么有个 1/2**：求导时指数 2 掉下来，正好和 1/2 抵消，梯度公式更干净。

### 5. 批量梯度下降

```
每步：θ := θ - α · (1/m) · Xᵀ · (X·θ - y)
```

- **行列形**：`X` 是 (m, n+1)，误差 `(Xθ - y)` 是 (m,)，`Xᵀ·误差` 是 (n+1,)——**一次矩阵乘**算出全部特征的梯度。
- **为什么是 `Xᵀ(预测-误差)`**：对每个 θ_j 求偏导，结果正是「第 j 个特征 × 误差」在样本上的平均，写成矩阵就是 `Xᵀ(误差)`。
- **批量**的含义：每一步都用**全部样本**算梯度，稳定但单步慢。

### 6. 学习率 α 与迭代次数

```
α 太小 → 收敛太慢
α 太大 → 代价震荡甚至发散（曲线上升）
epoch 太小 → 还没收敛；太大 → 浪费算力（简单问题通常无过拟合之虞）
```

本仓库 α 取 0.01、epoch 取 1500，是「稳定收敛」的常用起点。

### 7. 可视化验证（必做）

```
图 A 拟合效果
    单特征：原始散点 + 拟合直线
    多特征：预测值 vs 实际值，越贴近 y = x 越好
图 B 收敛曲线
    横轴 epoch、纵轴 cost，应单调下降并逐渐走平
    若震荡/上升 → 学习率太大，调小 α
```

### 8. 预测新样本

```
新样本 → 用训练时的 μ/σ 缩放 → 前面拼上 1 → 与 θ 做点积 → 得到预测值
```

## 易错点 / 常见坑

| 坑 | 说明 |
|---|---|
| 忘记特征缩放 | 多特征时不缩放，梯度下降震荡、收敛极慢 |
| 预测忘记同一套缩放 | 新样本必须用**训练时的 μ/σ**，不能用新数据自己算的 |
| 混淆 `*` 和 `@` | 预测值是 `X @ θ`（矩阵乘），不是逐元素乘 |
| 画拟合线坐标不一致 | 特征已缩放，画线时 x 要与预测值处于同一空间（或反变换回原始尺度） |
| 学习率过大 | cost 曲线上翘/震荡，说明步子太大会跨过最低点 |
| 偏置列重复 | 偏置已并入 θ 的 θ[0]，不要再单独加一个 b |
| 全量 vs 分批 | 本章是「批量」梯度下降，每步用全部样本 |
