# 06 · 前向传播 知识卡片

> **本章定位**：**手写神经网络的一层**。解决的核心问题是——**「神经元」到底在算什么，为什么用矩阵算比逐个循环快**。
>
> **承上启下**：把 04/05 的 `X·θ` 抽象成「单层 dense」；向后是 07/08 里 `Dense` 层的内部原理。

---

## 知识地图

```
单层 dense（全连接层）
├─ 神经元        a = g(w · a_in + b)   加权和 + 激活
├─ 一层多神经元  W 的「每一列」是一个神经元的权重
├─ 两种实现
│   ├─ 循环版    逐个神经元算 z=w·a_in+b，再 sigmoid
│   └─ 矩阵版    a_out = g(a_in · W + b)   一次矩阵乘算完
└─ 多层堆叠     前一层输出 = 后一层输入（sequential）
```

---

## 核心知识点卡片

### 1. 神经元 = 加权和 + 激活

```
a = g( w · a_in + b )
    └─ 加权和 ──┘   └g: 激活函数
```

- **是什么**：先把输入按权重加权求和、加偏置，再过一个非线性激活函数。
- **为什么**：加权和是「线性打分」，激活引入**非线性**，网络才可能拟合复杂函数。

### 2. 一层 = 多个神经元并行

- **约定**：权重矩阵 `W` 的**每一列**对应一个神经元的权重向量；`W` 的行数 = 输入维度，列数 = 神经元个数。
- **偏置** `b` 是长度 = 神经元个数的向量，每个神经元一个。

```
W 形如 (输入维度 × 神经元个数)
第 j 列 = 第 j 个神经元的权重
```

### 3. 输入是「行向量」

- 本仓库约定：`a_in` 是 1×n 的**行向量**，与 `W`(n×k) 相乘后得到 1×k 的输出行向量。

```
a_in (1×n) · W (n×k) = z (1×k)     # 一次算出 k 个神经元的加权和
a_out = g(z + b)                    # 再逐元素过激活
```

### 4. 两种实现：循环版 vs 矩阵版

```
循环版（概念直观）
    for j in 神经元个数:
        z_j = dot(a_in, W[:, j]) + b_j
        a_out[j] = sigmoid(z_j)

矩阵版（实际框架的做法）
    z     = a_in · W + b        # a_in · W 得到 [a_in·w1, a_in·w2, ..., a_in·wk]
    a_out = sigmoid(z)
```

- **为什么矩阵版快**：一次矩阵乘法把 k 个神经元的加权和全部算完，底层走优化过的 BLAS 库，避免 Python 层循环。
- **两者结果必须一致**——这是验证实现是否正确的好办法。

### 5. 多层堆叠 = sequential

```
a1 = dense(x,  W1, b1)     # 第 1 层：x 是原始输入
a2 = dense(a1, W2, b2)     # 第 2 层：上一层输出当输入
a3 = dense(a2, W3, b3)     # 第 3 层
f(x) = a3                  # 最后一层输出即最终预测
```

- **核心规律**：把上一层的输出**直接当作下一层的输入**串起来，就是完整前向传播。
- 这与 Keras 的 `Sequential` 顺序堆叠是同一件事。

---

## 易错点 / 常见坑

| 坑 | 说明 |
|---|---|
| W 的行列搞反 | **每一列**是一个神经元；行数=输入维度、列数=神经元数 |
| 忘记加偏置 | `z = a_in·W + b`，漏掉 `b` 会丢一个自由度 |
| 输入方向不一致 | 本仓库统一用**行向量**，与 `W` 相乘得到行向量输出 |
| 全用线性层 | 不加非线性激活，多层叠加仍等价于一层线性变换 |
| 循环版/矩阵版结果不一致 | 说明矩阵形状或索引对错了，可互相对照验证 |
